Palindrome Program in Java

Checking whether a string is palindrome is a common Java interview question. A palindrome is a word that reads the same forward and backward.

Problem Statement

Write a Java program to check whether a string is palindrome.

Example

Input: madam
Output: Palindrome

Java Code

public class Palindrome {
    public static void main(String[] args) {
        String str = "madam";
        String reversed = "";

        for(int i = str.length() - 1; i >= 0; i--) {
            reversed += str.charAt(i);
        }

        if(str.equals(reversed)) {
            System.out.println("Palindrome");
        } else {
            System.out.println("Not Palindrome");
        }
    }
}

Explanation

We reverse the string and compare it with the original string. If both are equal, the string is a palindrome.

Time Complexity

O(n) — We traverse the string once.

Space Complexity

O(n) — Extra space is used to store reversed string.
